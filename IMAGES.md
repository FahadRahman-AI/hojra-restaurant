# Image Guide — Hojra Restaurant

Drop your images into `public/images/` with these exact filenames.
No code changes needed — images appear automatically on refresh.

| File | Where it appears | Best content |
|------|-----------------|--------------|
| `hero.jpg` | Full-screen hero section | Restaurant exterior or interior wide shot |
| `story.jpg` | Story section beside text | Interior detail, candlelight, ambience |
| `dish-1.jpg` | Signature dish feature (55vh band) | Chinaki teapot stew — the hero dish |
| `gallery-1.jpg` | Gallery row, left column | Food close-up or signature dish |
| `gallery-2.jpg` | Gallery row, centre column | Table setting or interior |
| `gallery-3.jpg` | Gallery row, right column | Chef, kitchen, or atmosphere shot |
| `private-dining.jpg` | Private dining section | One of the dining rooms |

**Recommended dimensions:**
- Hero: 2400 × 1600px landscape
- Story & Private dining: 1200 × 1500px portrait (4:5 ratio)
- Signature dish: 2400 × 1200px landscape (wide)
- Gallery: 900 × 1200px portrait (3:4 ratio) for each

All images should be saved as high-quality JPEG.
